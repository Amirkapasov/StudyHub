# StudyHub: памятка для защиты

## 1. Как объяснить работу за минуту

«Мы сделали адаптивную версию StudyHub. На странице Study Tips расположение карточек и размер текста меняются через собственные media queries. На остальных страницах мы используем Bootstrap: сетку из 12 долей, адаптивные отступы, navbar, кнопки, карточки, карусель и форму. На маленькой ширине элементы перестраиваются, а меню сворачивается. Bootstrap лежит локально, поэтому сайт работает без интернета».

## 2. Media queries — css/media-queries.css

Базовые правила написаны для узкого окна. Это подход mobile first.

```css
.tips-grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 24px;
}

@media (min-width: 768px) {
    h1 { font-size: 38px; }
    .tips-grid { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 992px) {
    h1 { font-size: 48px; }
    .tips-grid { grid-template-columns: repeat(3, 1fr); }
}
```

- `display: grid` включает CSS Grid.
- `1fr` означает одну равную долю доступного пространства.
- `repeat(2, 1fr)` создаёт две одинаковые колонки.
- `gap: 24px` задаёт расстояние между карточками.
- `min-width: 768px` означает «ширина окна не меньше 768 CSS-пикселей».
- При ширине 1100px действуют оба media query. Последнее правило с таким же приоритетом заменяет предыдущее значение: будет три колонки.
- `max-width` означает «не больше указанной ширины». Пример есть в `css/style.css`: на узком экране уменьшается высота карусели.
- Это проверка ширины окна, а не определение модели телефона или компьютера.

Шрифты `h1`, `h2` и `p` меняются отдельно. Маленькая надпись `.eyebrow` сохраняет свой размер, потому что селектор класса имеет больший приоритет, чем селектор тега `p`.

Практика: поменяй 768 на 800; затем сравни страницу на ширине 790 и 810. Чтобы увеличить мобильный заголовок, измени базовый `h1`, а не правило внутри desktop media query.

## 3. Bootstrap Grid — index.html

```html
<div class="container">
    <div class="row g-4">
        <div class="col-12 col-lg-6">Текст</div>
        <div class="col-12 col-lg-6">Изображение</div>
    </div>
</div>
```

- `container` центрирует содержимое и ограничивает его ширину в зависимости от окна.
- `container-fluid` занимает всю доступную ширину.
- `row` — строка сетки. Внутри неё находятся колонки.
- Строка делится на 12 долей; число после `col` — количество занимаемых долей.
- `col-12` — вся строка; `col-lg-6` — половина строки от 992px.
- `col-12 col-md-6 col-lg-4` — одна колонка до 768px, две от 768px, три от 992px.
- `sm` начинается с 576px, `md` — с 768px, `lg` — с 992px.
- `g-4` — промежутки между колонками и рядами.

Практика: у трёх блоков на главной замени `col-lg-4` на `col-lg-6`. Два блока займут первую строку, третий перейдёт на следующую. Для пропорции 1:2 используй `col-lg-4` и `col-lg-8`.

CSS Grid (`display: grid`) и стандартная сетка Bootstrap — разные механизмы. Bootstrap Grid использует Flexbox и собственные media queries, уже записанные в файле библиотеки.

## 4. Отступы — классы в HTML

`margin` — внешний отступ, `padding` — внутренний. `gap` — промежуток между элементами в подходящем layout.

| Класс | Что делает |
|---|---|
| `p-3` | Внутренний отступ со всех сторон |
| `mt-4` | Внешний отступ сверху |
| `mb-0` | Убирает внешний отступ снизу |
| `px-3` | Внутренний отступ слева и справа |
| `py-5` | Внутренний отступ сверху и снизу |
| `ms-auto` | Автоматический отступ перед элементом; здесь отодвигает меню вправо |
| `p-3 p-lg-4` | Небольшой отступ по умолчанию, больший от 992px |
| `mt-auto` | В карточке с flex-column прижимает кнопку вниз |

В стандартном Bootstrap шкала: 0 → 0; 1 → 0.25rem; 2 → 0.5rem; 3 → 1rem; 4 → 1.5rem; 5 → 3rem. `rem` зависит от размера шрифта корневого элемента; при 16px класс `p-4` даёт 24px. Цифра 4 не означает 4px.

Практика: в форме замени `p-3 p-lg-4` на `p-2 p-lg-5` и сравни узкое и широкое окно.

## 5. Navbar — в начале основных HTML-файлов

- `navbar` — компонент навигации.
- `navbar-expand-lg` — меню полностью раскрыто от 992px; ниже доступно через кнопку.
- `navbar-toggler` — кнопка с иконкой меню.
- `collapse navbar-collapse` — сворачиваемый блок.
- `data-bs-toggle="collapse"` выбирает поведение Bootstrap.
- `data-bs-target="#mainNav"` указывает на блок с `id="mainNav"`.
- `aria-controls` сообщает вспомогательным технологиям, какой блок управляется кнопкой; `aria-expanded` сообщает состояние.

Практика: замени `navbar-expand-lg` на `navbar-expand-md` — полное меню появится от 768px. Если меняешь `id`, обнови также `data-bs-target` и `aria-controls`.

Bootstrap CSS рисует меню, а `bootstrap.bundle.min.js` обрабатывает нажатие. Без JS сворачиваемое меню и карусель работать не будут.

## 6. Кнопки — index.html и schedule.html

- `btn` задаёт основу кнопки.
- `btn-primary` — основной вариант; `btn-outline-primary` — контурный.
- `btn-lg` и `btn-sm` меняют размер.
- `btn-group` объединяет связанные кнопки. На Schedule они ведут к разделам страницы через `href="#weekly"` и `href="#dates"`.
- Ссылка `<a>` используется для перехода. `<button>` — для действия, например отправки формы или переключения слайда.

Практика: замени `btn-primary` на `btn-success`, а `btn-lg` на `btn-sm`. Для контурного варианта нужен полный класс `btn-outline-primary`, а не просто `btn-outline`.

## 7. Карусель — gallery.html

- `carousel-inner` содержит слайды `carousel-item`.
- У первого слайда есть `active`. При открытии активным должен быть ровно один слайд.
- Кнопки со значениями `data-bs-slide="prev"` и `"next"` переключают изображения.
- `data-bs-slide-to="0"` показывает первый слайд, `"8"` — девятый: отсчёт начинается с нуля.
- Все `data-bs-target` указывают на `#campusCarousel`.
- `data-bs-interval="false"` отключает автоматическое перелистывание. Сейчас слайды переключает пользователь.
- В `css/style.css` высота `.carousel-photo` равна 440px, а на узком экране — 300px.
- `object-fit: cover` заполняет рамку без растягивания фотографии; часть изображения может обрезаться.

Практика: поменяй мобильную высоту на 250px. Чтобы добавить десятый слайд, скопируй один `carousel-item`, поменяй `src` и `alt`, добавь индикатор с номером `9` и обнови подписи счётчика. Не добавляй второй `active`.

## 8. Карточки — courses.html

Структура: `card-group` → `card` → изображение `card-img-top` + содержимое `card-body`.
`card-title` — заголовок, `card-text` — описание. В первой группе три карточки, во второй две.
`flex-column flex-md-row` располагает карточки вертикально на узком экране и в строку от 768px.
`d-flex flex-column` внутри карточки и `mt-auto` у кнопки помогают выровнять кнопки по низу.

Практика: поменяй `height` у `.card-img-top` с 190px на 230px. Для нового курса скопируй целиком один `<article class="card">`.

## 9. Форма — contact.html и js/contact.js

- `form-control` оформляет текстовые поля и textarea; `form-select` — select.
- `form-check-input` и `form-check-label` оформляют checkbox и radio.
- `input-group` объединяет поле email со значком @.
- `label for="email"` связан с `input id="email"`; клик по подписи переносит фокус в поле.
- `required` не позволяет отправить незаполненное поле.
- `type="email"` включает проверку формата адреса браузером.
- У radio одинаковый `name="student"`: поэтому можно выбрать только один вариант.
- `rows="4"` задаёт начальную высоту textarea примерно в четыре строки.

В `contact.js` обработчик `submit` срабатывает после успешной встроенной проверки. `event.preventDefault()` отменяет обычную отправку формы. `result.hidden = false` показывает сообщение. Обработчик `input` снова скрывает его при редактировании.

Форма учебная: она не отправляет письма и не хранит данные. Для реальной отправки нужен сервер или отдельный сервис.

Практика: измени `rows` на 6, убери `required` у Message и проверь пустое поле. Затем верни обязательность. Чтобы поля Name и Email стояли рядом только от 768px, замени у них `col-sm-6` на `col-md-6`.

## 10. Доступность и проверка

`nav`, `main`, `section`, `article`, `footer` описывают назначение частей страницы. `alt` описывает изображение; пустой `alt` у логотипа уместен, потому что название StudyHub уже написано рядом. `visually-hidden` скрывает текст визуально, сохраняя его для программ чтения с экрана.

В браузере нажми F12 и включи режим устройства (в Chrome на Windows: Ctrl+Shift+M). Введи ширины 390, 767, 768, 991, 992 и 1440. Особенно полезно сравнивать соседние значения около порога.

Проверь Tab и Enter, кнопку меню, стрелки и индикаторы карусели, пустую и корректно заполненную форму. На Schedule таблица прокручивается в собственном блоке `table-responsive`, а остальная страница остаётся по ширине экрана.
