# Памятка для защиты

## Что изменилось

Мы сохранили исходный StudyHub и добавили требования Assignment 3. Bootstrap отвечает за сетку, отступы и поведение компонентов. В собственном CSS оставлены знакомые цвета, размеры, скругления и тени.

## 1. Media queries

Открой Courses → Media Queries demo. Эта страница не подключает Bootstrap.

В конце `css/media-queries.css`:

```css
.course { display: grid; grid-template-columns: 1fr; }
@media (min-width: 768px) {
    .course { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 992px) {
    .course { grid-template-columns: repeat(3, 1fr); }
}
```

`min-width` означает «ширина окна не меньше этого значения». До 768px работает одна колонка; от 768px — две; от 992px — три. `1fr` — равная доля свободного места. На большой ширине выполняются оба media query, но последнее правило с одинаковым приоритетом определяет итог.

Там же меняются размеры заголовка и абзацев. Для телефона правь базовый `font-size`, для планшета — блок 768px, для компьютера — блок 992px.

**Практика:** перенеси переход с 768 на 800px и сравни ширины 799 и 800.

## 2. Bootstrap Grid

На Home текст и фотография имеют `col-12 col-lg-6`. В футере три блока имеют `col-lg-4`.

- `container` центрирует содержимое и ограничивает ширину; `container-fluid` занимает доступную ширину.
- `row` — строка, внутри которой находятся колонки.
- В строке 12 долей. `col-12` занимает всю строку; `col-lg-6` — половину от 992px.
- `6 + 6 = 12`: две равные колонки. `4 + 4 + 4 = 12`: три.
- На Gallery `col-12 col-md-6 col-lg-4` даёт 1 / 2 / 3 фотографии в ряду.
- `sm` начинается с 576px, `md` — с 768px, `lg` — с 992px.
- `g-3` и `g-4` задают промежутки сетки.

**Практика:** для двух фотографий вместо трёх замени у фотографий Gallery `col-lg-4` на `col-lg-6`.

Стандартный Bootstrap Grid использует Flexbox. На странице Media Queries работает наш CSS Grid — `display: grid`.

## 3. Отступы

`margin` — внешний отступ, `padding` — внутренний.

| Класс | Что делает |
|---|---|
| `p-4` | Внутренний отступ со всех сторон |
| `px-4` / `py-3` | Внутренние отступы по горизонтали / вертикали |
| `mb-3` | Внешний отступ снизу |
| `m-0` | Убирает внешние отступы; `mb-3` отдельно задаёт нижний |
| `my-4 my-lg-5` | Вертикальные внешние отступы больше от 992px |
| `mx-auto` | Центрирует блок через автоматические боковые отступы |
| `ms-auto` | Автоматический отступ слева в нашем LTR-макете; сдвигает элемент вправо |
| `mt-auto` | В вертикальной flex-карточке прижимает кнопку вниз |

Шкала: 1 → 0.25rem; 2 → 0.5rem; 3 → 1rem; 4 → 1.5rem; 5 → 3rem. При корневом шрифте 16px класс `p-4` даёт 24px. Цифра в классе не означает пиксели.

**Практика:** увеличь отступ внутри карточки, заменив `p-4` у `card-body` на `p-5`.

## 4. Navbar

`navbar-expand-lg` раскрывает полное меню от 992px; ниже используется кнопка `navbar-toggler`. Её `data-bs-target="#mainNav"` должен совпадать с `id="mainNav"` у сворачиваемого блока. `data-bs-toggle="collapse"` выбирает поведение Bootstrap.

**Практика:** замени `navbar-expand-lg` на `navbar-expand-md` — полное меню появится от 768px.

CSS оформляет меню; `bootstrap.bundle.min.js` обрабатывает нажатия. `aria-expanded` сообщает вспомогательным технологиям, открыто ли меню.

## 5. Кнопки и режимы Gallery

`btn` — основа; `btn-primary` — заполненная кнопка; `btn-outline-primary` — контурная. `btn-sm` и `btn-lg` задают варианты размера. В нашем CSS сохранены прежние размеры текста кнопок и синий цвет.

В Gallery `btn-group` объединяет Grid и Slideshow. `data-bs-toggle="tab"` переключает панели. Их `data-bs-target` указывают на `#photo-grid` и `#photo-slideshow`. По умолчанию активна прежняя сетка.

**Практика:** замени `btn-primary` на `btn-success`, чтобы кнопка стала зелёной. Наш `.btn-primary` задаёт прежний синий через переменные Bootstrap `--bs-btn-*`.

## 6. Карусель

Gallery → Slideshow. В `carousel-inner` девять блоков `carousel-item`. Только первый первоначально имеет `active`.

- `data-bs-slide="next"` / `"prev"` — стрелки.
- `data-bs-slide-to="0"` — первый индикатор; `"8"` — девятый. Отсчёт начинается с нуля.
- Все кнопки указывают на `#campusCarousel`.
- `data-bs-interval="false"` отключает автоматическую смену.
- `.carousel-photo` задаёт высоту 440px, на узком экране — 280px.
- `object-fit: cover` сохраняет пропорции и заполняет рамку с возможным обрезанием краёв фото.

**Практика:** в нижнем media query поменяй 280px на 240px. Для нового слайда добавь `carousel-item` и соответствующий индикатор.

## 7. Карточки Courses

Прежние карточки получили `card`, `card-body`, `card-img-top` и контейнер `card-group`. Сохранены скругления 20px, изображение высотой 180px, тень и hover.

Правило `.course.card-group > .course-card` сохраняет старое поведение: `flex: 1 1 300px` позволяет карточке расти и сжиматься с начальной шириной 300px; `max-width: 380px` ограничивает рост. Группа переносит карточки на новую строку. Для задания на явную 12-дольную сетку показывай Home, футер или Gallery.

**Практика:** измени `height` у `.card-img-top` или `border-radius` у карточки.

## 8. Форма Contact

`form-control` оформляет поля и textarea; `form-select` — select; `form-check-input` и `form-check-label` — radio и checkbox. Раскладка About Us / форма использует `col-lg-6`.

`label for="email"` связан с `id="email"`. `required` делает поле обязательным; `type="email"` проверяет формат адреса. У radio одинаковый `name="reply"`, поэтому выбирается только один вариант.

В `contact.js` обработчик `submit` срабатывает после встроенной проверки браузера. `event.preventDefault()` отменяет отправку. `result.hidden = false` показывает результат проверки. При редактировании он скрывается. Данные не отправляются и не сохраняются.

**Практика:** убери `required` у Message, проверь пустое поле, затем верни атрибут.

## 9. Проверка перед защитой

F12 → режим устройства (Chrome: Ctrl+Shift+M). Проверь 390, 767, 768, 991, 992 и 1440px. Это ширина окна, а не определение устройства.

Покажи мобильное меню, Grid / Slideshow, стрелки и индикаторы, пустую и заполненную форму. Проверь Tab. Таблица Schedule прокручивается внутри `table-responsive`, не расширяя страницу.

Перед изменением параметра сначала объясни ожидаемый результат, затем измени его и проверь в браузере.
